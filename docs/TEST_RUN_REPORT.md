# گزارش اجرای آزمون ابزارها

## آنچه واقعاً اجرا شد

محیط اجرای این گزارش پایتون بدون FastAPI بود، پس فقط ابزارهایی اجرا شدند که وابستگی بیرونی ندارند.

| آزمون | نتیجه |
|---|---|
| مساحت از ابعاد فارسی (۲۵×۶۰ = ۱۵۰۰) | PASS |
| محاسبه‌گر مساحت بدون ابعاد چیزی حدس نمی‌زند | PASS |
| متره: کف، محیط و دیوار (۱۵۰۰ / ۱۷۰ / ۵۱۰) | PASS |
| متره بدون ابعاد چیزی حدس نمی‌زند | PASS |
| همهٔ ایجنت‌ها ابزار ثبت‌شده دارند | PASS |
| چک‌لیست سازه: گزارش خاک جاافتاده گزارش می‌شود | PASS |
| چک‌لیست متره: ارقام فارسی به‌عنوان ابعاد شناخته می‌شوند | PASS |
| چک‌لیست بدون متن: هیچ‌چیز ادعا نمی‌شود | PASS |
| رشتهٔ ناشناخته خطا می‌دهد | PASS |
| DXF: ساختار معتبر، ۸ خط، ۴ متن، فقط ASCII | PASS |
| DXF: فقط ASCII | PASS |

**جمع: ۱۱ از ۱۱ آزمون خالص PASS.**

## آنچه اجرا نشد

- `tests/test_tools_integration.py` نوشته شد اما **اجرا نشد**، چون FastAPI و httpx در این محیط نصب نیستند. این آزمون‌ها شامل مسیرهای HTTP، فهرست ایجنت‌ها، چت دمو، DXF، SVG و نگهبان دسترسی محلی هستند.
- مجموعهٔ کامل `pytest` اجرا نشد.
- رفتار اجرای زنده روی ویندوز و مرورگر تأیید نشده است.
- چک‌لیست رشته‌ای هنوز به پاسخ چت وصل نیست؛ بنابراین هیچ آزمون یکپارچه‌ای آن را در جواب ایجنت بررسی نمی‌کند.

## دستور اجرا روی ویندوز

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

نتیجهٔ آن را پس از اجرا به‌روزرسانی کنید؛ تا آن زمان این گزارش فقط همان ۱۱ آزمون خالص را تأیید می‌کند.
