# گزارش اجرای خشک ابزارها

این گزارش با اجرای `app/agents/tool_dry_run.py` در محیط بدون FastAPI و بدون شبکه تولید شد. وضعیت هر ابزار یکی از این‌هاست: **PASS** (اجرا و بررسی درست)، **FAIL** (نتیجه با انتظار نمی‌خواند)، **ERROR** (خطای اجرا)، **SKIPPED** (برای اجرا به سرور زنده یا کلید واقعی نیاز دارد، پس اینجا ساختگی اجرا نشد).

| ابزار | وضعیت | جزئیات |
|---|---|---|
| خواندن سند (`document_reader`) | SKIPPED | نیازمند مسیر آپلود FastAPI؛ در تست‌های یکپارچه پوشش داده شده |
| محاسبه‌گر مساحت (`area_calculator`) | PASS | مساحت ۱۵۰۰ متر مربع |
| دیاگرام SVG (`concept_svg`) | SKIPPED | از `/api/v1/concept/drawing` سرو می‌شود؛ در تست‌های یکپارچه پوشش داده شده |
| چک‌لیست رشته‌ای (`discipline_checklist`) | PASS | ۲ مورد موجود، ۲ مورد جاافتاده |
| مدل زبانی آنلاین (`online_model`) | SKIPPED | تنظیم نشده: `LLM_API_KEY` و `LLM_MODEL` |
| متره‌ی هندسی (`quantity_takeoff`) | PASS | کف ۱۵۰۰ و دیوار ۵۱۰ متر مربع |
| پایش گردش کار (`workflow_monitor`) | SKIPPED | وابسته به رویدادهای زنده‌ی حافظه؛ در تست‌های یکپارچه پوشش داده شده |

**خلاصه:** PASS ۳ · SKIPPED ۴ · FAIL ۰ · ERROR ۰

## نکته‌ها

- هیچ ابزاری در اجرای خشک خطای اجرا نداد.
- چهار ابزار SKIPPED هستند نه PASS؛ عدم اجرای آن‌ها به معنی سالم بودنشان نیست.
- اجرای خشک هیچ درخواست شبکه‌ای نمی‌زند و هیچ کلیدی را نمی‌خواند.
- برای تأیید ابزارهای SKIPPED باید تست یکپارچه روی ویندوز اجرا شود.
