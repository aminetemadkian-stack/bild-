# دستیار طراحی معماری چندایجنتی | نسخه‌ی آغازین

## نقش دستیار

دستیار به‌عنوان متخصص ارشد معماری، نقشه‌کشی و طراحی داخلی تنظیم شده و به‌صورت پیش‌فرض فارسی پاسخ می‌دهد. متن رابط، مستندات و پیام‌های خطا فارسی هستند.

پروژه‌ی پایه‌ی Python + FastAPI برای ساخت یک دستیار چندایجنتی در حوزه‌ی معماری، طراحی داخلی و هماهنگی رشته‌ها. مناسب توسعه روی Windows 10/11.

> **محدودیت ایمنی و حرفه‌ای:** این نسخه یک MVP نرم‌افزاری برای جمع‌آوری ورودی‌ها و تولید گزارش مفهومی است؛ نقشه‌ی اجرایی، محاسبه‌ی سازه، تأیید حریق/تأسیسات یا جایگزین مهندس معمار و مهندسان دارای صلاحیت نیست. خروجی‌ها باید پیش از استفاده‌ی واقعی بازبینی شوند.

## چه چیزی دارد؟

- رابط فارسی راست‌چین: چت، تنظیم و تست اتصال API، داشبورد وضعیت ایجنت‌ها و ابزار دیاگرام مفهومی SVG
- ضمیمه‌ی چندفایلی تا ۱۰ فایل، حداکثر ۱۲ مگابایت برای هر فایل و ۲۰ مگابایت مجموع
- استخراج متن از TXT/MD/CSV/JSON، PDF، DOCX، XLSX و PPTX؛ پردازش PNG/JPEG/WEBP/GIF در صورت پشتیبانی مدل از تصویر
- تاریخچه‌ی چت اختیاری و خاموش به‌صورت پیش‌فرض؛ حذف تکی با آیکون سطل و حذف همه با دکمه‌ی جداگانه، به‌علاوه‌ی پاک‌سازی خودکار با مهلت انتخابی
- بدون آموزش خودکار؛ حداکثر ۵۰۰ پیام در SQLite محلی

- FastAPI با Swagger در `/docs`
- SQLite محلی برای ذخیره‌ی پروژه‌ها و نتایج اجرا
- مسیرهای API برای سلامت سرویس، فهرست ایجنت‌ها، ساخت پروژه و اجرای تحلیل مفهومی
- ایجنت‌های ماژولار: هماهنگ‌کننده، معماری، طراحی داخلی، سازه، مکانیک، برق، حریق/ایمنی، متره/برآورد و کنترل الزامات
- حالت نمونه بدون کلید API، و اتصال عملیاتی به APIهای سازگار با OpenAI Chat Completions
- کلید API فقط از فایل محلی `.env` خوانده می‌شود؛ در کد یا Git قرار ندهید
- هر ایجنت خروجی JSON ساخت‌یافته می‌گیرد و schema پایه اعتبارسنجی می‌شود
- فایل‌های اجرا برای ویندوز و تست‌های پایه

## مدل اجرای شخصی و آنلاین

وب‌اپ روی رایانه‌ی شخصی و به‌صورت محلی روی `127.0.0.1` اجرا می‌شود؛ پیش‌فرض، آن را برای اینترنت عمومی باز نمی‌کند. برای پاسخ مدل، درخواست‌ها از اینترنت به API انتخابی شما ارسال می‌شوند، بنابراین اتصال اینترنت و کلید/حساب ارائه‌دهنده لازم است. کلید در `.env` محلی ذخیره می‌شود و به صورت رمزنگاری‌شده نیست؛ دسترسی ویندوز به پوشه‌ی برنامه را محافظت کنید.

ایجنت‌ها در این نسخه برای کارهای طراحی ساختمان و هماهنگی رشته‌ها تعریف شده‌اند، نه «هر کار عمومی». هر ایجنت فهرست ابزار محدود خودش را دارد؛ از جمله خواندن سند، محاسبه‌ی مساحت ساده، دیاگرام SVG مفهومی، چک‌لیست رشته‌ای، مدل آنلاین و پایش گردش کار. از صفحه‌ی چت می‌توان ایجنت را دستی انتخاب کرد یا گذاشت سامانه بر اساس متن، ایجنت مناسب را پیشنهاد کند. ابزارهای مخرب یا تغییر دهنده‌ی فایل/سیستم در اختیار ایجنت‌ها نیستند.

## اجرا در Windows

1. Python 3.11 یا جدیدتر نصب باشد.
2. فایل ZIP را Extract کنید و PowerShell را در پوشه‌ی پروژه باز کنید.
3. اجرا کنید:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\\scripts\\setup.ps1
.\\scripts\\run.ps1
```

یا `run.bat` را اجرا کنید. سپس `http://127.0.0.1:8000/` را برای رابط گرافیکی یا `http://127.0.0.1:8000/docs` را برای API باز کنید.

### فعال‌کردن مدل زبانی واقعی

در `.env`، مقدار `LLM_PROVIDER` را به `openai_compatible` تغییر دهید و `LLM_BASE_URL`، `LLM_API_KEY` و `LLM_MODEL` را مطابق ارائه‌دهنده وارد کنید. برای OpenAI، ریشه‌ی API معمولاً `https://api.openai.com/v1` است. سرور را دوباره اجرا کنید. هیچ کلیدی را در درخواست‌های API، کد یا مخزن عمومی وارد نکنید. درخواست هر ایجنت به provider ارسال می‌شود؛ هزینه و سیاست حفظ داده به ارائه‌دهنده بستگی دارد. اطلاعات محرمانه‌ی پروژه را بدون مجوز وارد نکنید.

## تست سریع API

در Swagger، ابتدا `POST /api/v1/projects` را با نمونه زیر بزنید:

```json
{
  "name": "Quick Service",
  "building_type": "commercial",
  "location": "Tehran, Iran",
  "brief": "فروش فیلتر روغن و هواکش خودرو با فروشگاه و انبار",
  "site": {"width_m": 25, "length_m": 60, "clear_height_m": 3},
  "spaces": ["فروشگاه", "انبار", "کانتر تحویل", "دریافت بار"]
}
```

شناسه‌ی پاسخ را در `POST /api/v1/projects/{project_id}/runs` وارد کنید. برای گرفتن نتیجه از `GET /api/v1/runs/{run_id}` استفاده کنید.

## معماری توسعه

- هر ایجنت یک وظیفه‌ی مشخص و خروجی JSON دارد.
- coordinator ایجنت‌ها را اجرا و خروجی‌ها را تجمیع می‌کند.
- اتصال OpenAI-compatible در `app/agents/llm_client.py` پیاده‌سازی شده است؛ `LLM_PROVIDER=openai_compatible` آن را فعال می‌کند. برای providerهایی با قرارداد متفاوت، adapter جداگانه بسازید. کلید فقط در فایل محلی `.env` باشد.
- برای مدل‌سازی واقعی، گام‌های بعدی می‌تواند افزودن export به DXF/IFC و اتصال به ابزار CAD/BIM باشد. خروجی تصویری این MVP، نقشه‌ی قابل ساخت تولید نمی‌کند.

### نگهداری داده و محدودیت فایل‌ها

مدل را خودکار آموزش نمی‌دهیم. تاریخچه به‌صورت پیش‌فرض خاموش است؛ در صورت فعال‌سازی، متن پیام‌های کاربر و پاسخ دستیار در SQLite محلی ذخیره می‌شود، برای حفظ زمینه به مدل ارسال می‌شود، تا سقف ۵۰۰ پیام نگه داشته می‌شود و با اجرای برنامه، هر ساعت و هنگام درخواست تاریخچه، داده‌های منقضی‌شده حذف می‌شوند. مدت نگهداری را از ۱ تا ۳۶۵ روز انتخاب کنید و هر زمان می‌توانید تاریخچه را دستی پاک کنید. فایل‌های ضمیمه و متن استخراج‌شده از آن‌ها در تاریخچه ذخیره نمی‌شوند.

در حالت تاریخچه‌ی روشن، متن گفتگو برای حفظ زمینه به مدل فرستاده می‌شود. فایل‌های ضمیمه در تاریخچه ذخیره نمی‌شوند، اما محتوای فایل در همان درخواست به ارائه‌دهنده‌ی مدل می‌رود. بهبود قابلیت‌ها از مسیر ارتقای نرم‌افزار است، نه آموزش خودکار یا انباشت نامحدود داده.

## مسیر توسعه‌ی پیشنهادی

1. تکمیل فرم ورودی پروژه و نیازمندی‌ها
2. اتصال provider زبانی با خروجی ساخت‌یافته و بررسی schema
3. مدیریت فایل‌های ورودی: PDF، DWG/DXF، عکس و گزارش خاک
4. گردش‌کار بازبینی انسانی، نسخه‌بندی و گزارش منابع
5. اتصال CAD/BIM, IFC/DXF, و آزمون با پروژه‌های واقعی
6. امنیت، کنترل دسترسی، لاگ ممیزی و استقرار داخلی

## تست انقضای تاریخچه

در پوشه‌ی پروژه اجرا کنید:

```powershell
.\\.venv\\Scripts\\python.exe -m pytest -q
```

تست‌ها زمان ثابت تزریق می‌کنند و انقضای دقیق در مرز زمان، پاک‌سازی خودکار هنگام خواندن، حفظ پیام‌های معتبر، مدت نگهداری و سقف ۵۰۰ پیام را بررسی می‌کنند؛ نیازی به صبر واقعی یا اتصال شبکه نیست.

## APIهای اصلی

- `GET /` رابط کاربری
- `POST /api/v1/chat` چت و فایل‌های ضمیمه
- `GET/POST /api/v1/settings` تنظیم اتصال، بدون بازگرداندن کلید
- `POST /api/v1/settings/test` تست واقعی اتصال
- `GET /api/v1/agents/status` وضعیت ایجنت‌ها و رخدادها
- `POST /api/v1/concept/drawing` دیاگرام SVG مفهومی
- `DELETE /api/v1/chat/history/{message_id}` حذف یک پیام
- `DELETE /api/v1/chat/history` حذف همه‌ی پیام‌ها
- `GET /health` سلامت سرویس
