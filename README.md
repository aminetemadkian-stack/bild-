# دستیار طراحی معماری و نقشه‌کشی ساختمان (ArchAI)

دستیار چندایجنتی فارسی برای معماری، نقشه‌کشی، طراحی داخلی و هماهنگی رشته‌های ساختمان. اجرا با FastAPI روی ویندوز.

## قابلیت‌ها
- چت فارسی و راست‌چین با پشتیبانی از فایل‌های PDF، Word، Excel، PowerPoint و متن
- ۸ ایجنت تخصصی: معماری، طراحی داخلی، سازه، مکانیک، برق، حریق و ایمنی، متره و برآورد، ضوابط
- ابزارهای محلی: متره‌ی هندسی، محاسبه‌ی مساحت، دیاگرام SVG مفهومی، خروجی DXF، چک‌لیست رشته‌ای
- تاریخچه‌ی چت اختیاری با پاک‌سازی خودکار و حذف تکی
- تست‌های خودکار برای انقضای تاریخچه، متره و DXF

## نصب و اجرا در ویندوز
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\setup.ps1
.\scripts\run.ps1
```
سپس آدرس `http://127.0.0.1:8000/` را باز کنید. راهنمای کامل در فایل `README_FA.md` است.

## تنظیم مدل زبانی
در صفحه‌ی «اتصالات API» یا فایل `.env` مقدار `LLM_PROVIDER` را روی `openai_compatible` بگذارید و آدرس، نام مدل و کلید را وارد کنید. حالت پیش‌فرض، نمونه است و بدون اینترنت کار می‌کند.

## اجرای تست‌ها
```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## محدودیت مهم
خروجی‌ها مفهومی هستند. نقشه‌ی اجرایی، محاسبه‌ی سازه، تأیید حریق و مجوز شهرداری را تولید یا جایگزین نمی‌کنند. تمام نقشه‌ها باید توسط معمار و مهندسان دارای صلاحیت در محل بررسی و امضا شوند.
