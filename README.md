# دستیار طراحی معماری و نقشه‌کشی ساختمان (ArchAI)

دستیار چندایجنتی فارسی برای معماری، نقشه‌کشی، طراحی داخلی و هماهنگی رشته‌های ساختمان، با FastAPI و اجرا روی ویندوز.

## قابلیت‌ها
- چت فارسی (راست‌چین) با پشتیبانی از فایل‌های PDF، Word، Excel، PowerPoint و متن
- ۸ ایجنت تخصصی: معماری، طراحی داخلی، سازه، مکانیک، برق، حریق و ایمنی، متره و برآورد، ضوابط
- ابزارهای واقعی: متره‌ی هندسی، محاسبه‌ی مساحت، دیاگرام SVG مفهومی، خروجی DXF، چک‌لیست رشته‌ای
- تاریخچه‌ی چت اختیاری با پاک‌سازی خودکار و حذف تکی
- تست‌های خودکار برای انقضای تاریخچه، متره و DXF

## نصب و اجرا (ویندوز)
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\\scripts\\setup.ps1
.\\scripts\\run.ps1
```
سپس `http://127.0.0.1:8000/` را باز کنید. راهنمای کامل در `README_FA.md` است.

## تنظیم مدل زبانی
در صفحه‌ی «اتصالات API» یا فایل `.env` مقدار `LLM_PROVIDER=openai_compatible` را تنظیم کنید و آدرس، نام مدل و کلید را وارد کنید. پیش‌فرض حالت نمونه است و بدون اینترنت کار می‌کند.

## تست‌ها
```powershell
.\\.venv\\Scripts\\python.exe -m pytest -q
```

## محدودیت مهم
خروجی‌ها مفهومی هستند و نقشه‌ی اجرایی، محاسبه‌ی سازه، تأیید حریق یا مجوز شهرداری نیستند. تمام نقشه‌ها باید توسط معمار و مهندسان دارای صلاحیت در محل بررسی و امضا شوند.
